## 快速使用

1. 在导航站按名称、用户名、功能或标签查找机器人，也可按用途筛选。
2. 打开对应的 `https://t.me/用户名` 链接，核对账号后点击 Start。
3. 要查找群组、频道或资源，请在具体的搜索机器人中发送关键词；本站搜索只查找目录。
4. 不要向陌生机器人提供密码、登录验证码或其他敏感信息。

## 数据与检查说明

自动检查 Telegram 公开预览页，不会向机器人发送消息。页面存在或有公开月活，不代表功能、安全性或内容质量已经验证。月活缺失时不推测；新收录项可能仍待检查。

临时错误保留历史数据；第二次失效观察标记失效，第三次隐藏，JSON 中留痕。实际使用异常仍需要人工复核。

## 本地运行与部署

无需 Node 构建或网站后端，生成网站只依赖 Python 标准库。

```powershell
python scripts/render_readme.py
python scripts/build_site.py
python scripts/validate.py
python -m http.server 8000 --directory docs --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/`。完整配置、测试和 Cloudflare Pages 部署步骤见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## 维护与贡献

机器人数据统一维护于 `data/bots.json`，请勿直接手改生成的表格和网站。新增或修改后运行生成与校验命令。字段和收录规则见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

自有机器人入口由 `data/site.json` 指定，已按站长提供的后台格式使用 `start=nav_0` 统计导航站来源。第三方邀请参数填写在条目的 `referralStart` 字段，并标注「邀请推广」。导航站与机器人后端相互独立。
